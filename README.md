
# Human Resource Management System (HRMS)

A console-based Human Resource Management System developed in Java using Object-Oriented Programming principles and software design patterns.

## Features

- Employee management for full-time, part-time, and contract employees
- Payroll processing, including salary calculations, bonuses, taxes, and deductions
- Employee leave requests and approval management
- Employee registration and promotion management
- Department-based payroll reporting
- Employee authentication and role-based operations
- File-based data storage

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- JUnit 5
- Eclipse IDE
- File I/O

## Design Patterns

The application implements several software design patterns:

- **Factory Pattern:** Creates different employee types.
- **Strategy Pattern:** Separates payroll calculation strategies.
- **Decorator Pattern:** Supports additional salary components such as bonuses and overtime.

## Project Structure

The project contains Java source files for employee management, payroll processing, leave management, authentication, and reporting.

## How to Run

1. Clone or download the repository.
2. Open Eclipse IDE.
3. Select File > Import > Existing Projects into Workspace.
4. Select the project directory.
5. Run the application's main Java class.

## Testing

JUnit 5 is used to test selected application functionality.
